A private quality documentation platform built as a mobile app for employees and an admin interface for management.

The system lets workers log in on their phones, quickly find the correct project through a structured flow of project, position, order number, and workstation, and then complete a prefilled quality checklist. The form supports checkbox answers, free-text responses, and taking photos directly from the phone. Once submitted, the app automatically generates a PDF document with the answers, images, user name, and timestamp.

On the admin side, admins can create and manage quality document templates, define checklist items, set the answer type for each item, and control access rights for users and workstations. Admins can also manage submitted forms, review generated PDFs, and correct or update completed information when needed.

The project was designed to simplify quality control, reduce manual paperwork, and make documentation fast and accessible in both production and supervisory workflows.
